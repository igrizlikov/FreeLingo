# FreeLingo 0.6.9 — единый контекст перевода и жизненный цикл окон

- TranslateGemma 4B рекомендуется для перевода на русский и выбрана по умолчанию **для новых установок**. Настройки уже существующих пользователей остаются без изменений.
- Основное окно, ⌘4 и сравнительный режим используют одинаковый режим генерации и переводят короткие документы (до 3000 символов) **одним запросом**. Это уменьшает расхождения, вызванные разбиением абзацев. Для длинных документов остаётся безопасное разбиение.
- NSWindow/NSPanel явно сохраняются при закрытии, чтобы повторное открытие настроек и переводчика не обращалось к освобождённым окнам. Добавлены диагностические NSLog события без текста пользователя. **Причина пользовательского падения пока не подтверждена без .ips**.
- Сертификат подписи приложения, GitHub Secrets, Sparkle и установленные GGUF не меняются.

## Проверка на Mac
1. Обновить через Sparkle, сохранить выбранную TranslateGemma, проверить версию 0.6.9.
2. Один и тот же оригинальный английский текст перевести через основное окно и ⌘4 в русский. Сравнить формулировки и время.
3. Десять раз выполнить перевод → открыть настройки → закрыть → снова открыть.
4. При повторении падения сохранить ~/Library/Logs/DiagnosticReports/FreeLingo*.ips и передать отчёт (проверив его на персональные данные).

## Статус
Офлайн-статические тесты и структура ZIP: выполняются при подготовке. Нативная компиляция и UI-тесты — только GitHub Actions/macOS.
