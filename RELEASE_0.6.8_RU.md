# FreeLingo 0.6.8 — компактное меню и настройки

- Значок в строке macOS теперь показывает ровно два пункта: **Настройки…** и **Завершить FreeLingo**.
- Убраны прочие команды и переключатели из выпадающего меню.
- Взамен появилось обычное окно настроек AppKit с разделами: **Основные**, **Перевод**, **Горячие клавиши**, **Действия**.
- Сохранены возможности выбора моделей, проверки Sparkle-обновлений, сравнения Hy-MT2 и TranslateGemma, диагностического журнала, OCR, перевода выделения и буфера обмена, изменения сочетаний, автозапуска, Dock и экспериментальных режимов русского.
- Настройки применяются сразу, без модального диалога «Сохранить».
- Горячие клавиши сохраняются, даже когда команды отсутствуют в выпадающем меню.

## Проверка

Статические проверки в `python3 tests/check_release.py` и `python3 tests/test_compact_menu.py`.
Компиляция Objective-C/AppKit, подпись и тест реального интерфейса на macOS пока не выполнены. Использовать GitHub Actions на macos-15-arm64 и проверить окно в реальном приложении.

## Обновление

Оставить прежние Sparkle-ключи и сертификат подписи macOS. Для публикации загрузить ZIP исходников в корень GitHub и запустить `Publish FreeLingo signed update` с параметром `source_zip`.
