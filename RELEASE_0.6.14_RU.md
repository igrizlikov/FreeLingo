# FreeLingo 0.6.14 — оптимизация скорости TranslateGemma 12B

## Что изменилось
- TranslateGemma 12B переводит в одном запросе английские/европейские тексты длиной до 3600 символов и 5200 байт (раньше порог составлял 3000). Рассказ около 3014 символов из пользовательского журнала теперь не разбивается на 9 отдельных запросов.
- Для более длинных документов TranslateGemma 12B группирует соседние строки в блоки до 3000 символов / 3800 байт, а не выполняет HTTP-запрос для каждой строки. На границах блоков переводы соединяются с исходными разделителями строк; разделение чрезмерно длинных строк сохраняется.
- Для китайского и японского сохранён старый осторожный предел «целиком» 1300 символов.
- Новый журнал `perf` записывает время полного ответа (wall_ms) и, если движок отдаёт их, количество входных/выходных токенов и времена обработки (`prompt_n/prompt_ms/predicted_n/predicted_ms`). Журнал `backend` показывает повторное использование запущенной модели или время её запуска.
- Параметры генерации TranslateGemma не изменены: temperature 0; 12B модель/квантование остаются прежними; Metal 99 слоёв, контекст 6144.

## Верификация
Локально: `python3 tests/check_release.py`, `python3 tests/test_0614_speed.py`, shell/plist/ZIP. Rust unit tests в CI: `cargo test --target aarch64-apple-darwin` (нужен Mac); `llama-server` и Metal можно измерить только в macOS.

## Обязательные сценарии на Mac
1. TranslateGemma 12B: один и тот же английский текст ~3000-3300 символов через главное окно и ⌘4; оба должны показать `layout=whole chunks=1` с совпадающими входными/выходными хешами.
2. Более длинный текст >4000 символов: `layout=packed`, ожидается существенно меньше блоков, чем число непустых строк. Сверить точность, имена и абзацы; ускорение не гарантировано без измерения.
3. Проверить короткую фразу, перевод китайского, повторный перевод без перезапуска модели и возврат из настроек без падения.
4. Если у 12B исправились показатели скорости, сравнить `perf wall_ms` и, при наличии, `predicted_n/predicted_ms` с 0.6.13 на ОДИНАКОВЫХ текстах/модели.

Разрешения системы, Sparkle, подпись, модели и меню сохранены.
