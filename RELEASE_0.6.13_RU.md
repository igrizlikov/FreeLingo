# FreeLingo 0.6.13 — короткие фразы и TranslateGemma 12B

- Для TranslateGemma 4B и 12B добавлен явный выбор исходного языка в главном окне и окне ⌘4 (Из: Авто/Английский/Русский/Китайский/Французский/Итальянский).
- Если NaturalLanguage не может определить короткую фразу, FreeLingo выводит подсказку вместо отказа с требованием выделить длинный фрагмент. Выбор исходного языка в быстром окне сразу перезапускает перевод.
- Исправлена передача обязательной языковой пары в TranslateGemma 12B; раньше `en>ru` формировалось только для 4B, хотя Rust требовал пару для обеих моделей.
- A/B-сравнение использует язык, выбранный в главном окне.
- Веса моделей и пользовательский выбор модели не меняются.

## Проверки
Статические проверки и синтаксис сценария сборки выполняются в Linux. Требуются сборка GitHub Actions на macOS и реальное тестирование коротких фраз.
