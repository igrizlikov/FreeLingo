# FreeLingo 0.6.7 — диагностическое сравнение переводчиков

## Добавлено

- TranslateGemma 4B Q4_K_M (2,49 ГБ) в меню моделей: загрузка в приложение
  по HTTPS, проверка SHA-256 и GGUF.
- Отдельный JSON-шаблон запроса TranslateGemma с определёнными исходным и
  целевым языками (`chat_template_kwargs`); никакого повторного перевода через
  Qwen по умолчанию.
- Команда меню «Сравнить Hy-MT2 и TranslateGemma…» выполняет перевод
  одного исходного текста обеими моделями последовательно и показывает оба
  результата и длительность обработки. Ранжирование по литературности вручную.
- Команда «Открыть журнал перевода…»: локальный журнал сообщает, почему
  Qwen-вычитка принята, отклонена или ничего не изменила. Без текста оригинала.
- Корпус из 14 контрольных текстов на русском, английском, китайском,
  французском и итальянском; повторяемый macOS-бенчмарк в `tests/`.

## Осторожно

- TranslateGemma пока не запускалась со встроенным llama.cpp на настоящем Mac.
  Возможны ошибки специализированного Jinja-шаблона, требующие обновления
  закреплённой версии llama.cpp.
- Native macOS компиляция 0.6.7 пока не подтверждена. Нужен зелёный GitHub
  Actions run и ручной тест на компьютере пользователя.
- Качество на уровне DeepL НЕ подтверждено и не обещается.
- Qwen остаётся отдельной опцией улучшения текста и вычитки. Удалять её
  до завершения тестов не нужно; вычитку лучше оставить выключенной.
- Лицензия весов TranslateGemma — Gemma Terms, не MIT. Весов в архиве нет.
- Для автообновлений необходимо использовать тот же Sparkle EdDSA и
  постоянный сертификат FreeLingo Local Signing, что и в 0.6.6.

## Что проверить после установки

1. В менеджере скачать TranslateGemma 4B; вес скачивается только по выбору.
2. В главном окне вставить «My Wonderful Family», целевой язык — Русский.
3. В меню выбрать «Сравнить Hy-MT2 и TranslateGemma…».
4. Сравнить оба ответа по «родился последним», «нервная девочка»,
   «длительные прогулки», «хорошо проводить время» и двум братьям.
5. При включении вычитки проверить журнал (без исходного текста).
6. Проверить сохранение разрешения «Универсальный доступ» после обновления
   с 0.6.6 до 0.6.7 на одном сертификате.
