# FreeLingo 0.5.4 — Replica Audit Hotfix

**Статус:** кандидат на проверку, не готовый подтверждённый релиз. macOS GUI не тестировался в текущей Linux-среде.

## Исправления

- SHA-256 больше не резервирует 1 МиБ на стеке GCD: использует 64 КиБ heap memory с обработкой отсутствия памяти.
- Скачанные файлы проверяются по сигнатуре GGUF и минимальному размеру, отдельно для каждой модели.
- Защита от устаревших событий `NSURLSession` и UI progress во время проверки SHA.
- Нельзя случайно удалить/перезаписать предыдущий установленный GGUF до корректной установки нового файла.
- Fallback «Заменить» проверяет активное исходное приложение и неизменность выделенного текста непосредственно перед событием ⌘V.
- macOS CI может скачать Qwen3-0.6B, сверить SHA-256, запустить встроенный llama-server и реально проверить запрос на перевод.
- Версия приложения и DMG синхронизированы: 0.5.4; архив сборки включает `.dmg.sha256`.

## Важно

Новая сборка DMG должна пройти GitHub Actions, а загрузка и перевод — ручной тест на Mac. Если CI показывает Failure, приложи **лог build**, а не только общий статус.

Самостоятельные файлы из `native/`, `src/`, `assets/`, `tests/`, `.github/workflows/` и `build-macos.sh` должны попасть в репозиторий вместе. Не заменяй один `ModelManager.inc`, оставив старый workflow и старые тесты, если хочешь полную проверку 0.5.4.
