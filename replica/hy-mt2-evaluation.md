# Тесты качества Hy-MT2 на FreeLingo 0.6.4

Источник эталонного текста: replica/story-en.txt (пользовательский тест «My Wonderful Family»).

Проверить на Mac (отдельно 7B и 1.8B):
1. Скачивание из менеджера → SHA-256 → статус «Установлена» без падений.
2. Пять языков ru/en/zh/fr/it. Для каждого из 20 направлений (источник ≠ цель) использовать по 2 фразы и естественные выражения. Не выдавать тесты на статике за успешный перевод.
3. На английском рассказе → русский проверить: «два брата», «самый младший», «медсестра», «недалеко от гор», «прекрасно проводим время». Текст не должен быть китайско-русской смесью.
4. Режим «Улучшить текст» на Hy-MT2 должен выдавать понятное сообщение о необходимости Qwen3; перевод остаётся работоспособным.
5. С выключенным интернетом повторить 3 перевода.
6. Длинный текст по абзацам, несколько последовательных запросов, отмена и перезапуск приложения.
7. 0.6.3 → 0.6.4 через Sparkle (без DMG); ранее установленная Qwen3 не удаляется.

Статус на момент подготовки: всё перечисленное НЕ ПРОВЕРЕНО на реальном Mac. CI проверяет пакет и тесты Rust, а не качество реального перевода.
