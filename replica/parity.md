# Replica Audit: DeepL → FreeLingo 0.5.4

Исходный референс: предоставленные скриншоты DeepL (окна основного перевода, Write, Files, History, 5 разделов настроек, горячие клавиши, popup Copy/Edit/Replace). Код DeepL не используется.

**Подтверждено сборкой:** FreeLingo 0.5.1 собирался в CI macOS (скриншот GitHub Actions #3, Success, 1 artifact). Это не доказывает работоспособность в GUI и не относится автоматически к новой 0.5.4.

**Подтверждено кодом:** есть локальный движок Rust + llama-server, выбор/загрузка GGUF, текстовое окно, быстрый popup, Accessibility, OCR, history текущей сессии, hotkeys, TXT/MD.

**Недостатки паритета с DeepL:** нет полноценного перевода документов с сохранением форматирования (PDF/DOCX/PPTX); нет развитого словаря с альтернативами; нет TTS и настроек скорости; нет постоянной истории; не все оригинальные настройки реализованы; отдельный UI и качество Qwen не эквивалентны DeepL.

**Главный приоритет:** получить на реальном Mac успешный сценарий «скачать 0.6B → SHA совпал → перевести русский/английский → ⌘4 popup → безопасная замена». Пока до выполнения E2E не маркировать приложение как готовый стабильный релиз.

Источник статусов: `replica/features.csv`. Оценка возможностей — не оценка качества переводов.
