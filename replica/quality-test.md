# FreeLingo 0.6.1: критерии приемки

1. Запустить новую FreeLingo.app; в меню «Модели» скачать Qwen3 4B либо 8B. Провести тестовый перевод текста «My Wonderful Family» со входными 2 brothers / 1 sister / nurse.
2. Убедиться, что перевод не содержит `护士`, не меняет два брата на одного, не удаляет профессию матери и передает «have a good time» естественно. Такие требования не выполняются автоматически наличием prompt: это ручная проверка.
3. Проверить «Редактировать» в popup: поле принимает ввод, кнопка переключается в «Готово»; «Копировать» отдаёт изменённый вариант. Повторить 10 раз.
4. Закрыть popup, запустить повторный перевод; режим редактирования сброшен.
5. Проверить «Заменить» только на тестовом тексте в TextEdit (без потери другого текста).
6. Проверить включение режима без Dock и запуск из меню в macOS, отсутствие повторных окон и падений.
7. Если происходит crash, сохранить `.ips` из DiagnosticReports и указать номер запуска GitHub Actions.
