# FreeLingo 0.6.3 — приемка качества и автообновления

- Исходная версия: установленная 0.6.2, модель Qwen3 4B уже на диске, рабочая связка горячих клавиш.
- Целевой выпуск: 0.6.3, номер сборки 13, тот же ключ Sparkle Ed25519.
- Автообновление: в 0.6.2 «Проверить обновления» -> 0.6.3 -> «Установить» -> перезапуск -> «О программе» показывает 0.6.3. Не скачивать DMG вручную.
- Модели: ранее загруженный `Qwen3-4B-Q4_K_M.gguf` сохранён на диске; перевод возможен без Интернета.
- Тестовый текст: `replica/story-en.txt`. Проверить заголовок «Моя замечательная семья», 2 брата, 1 сестру, мать-медсестру, отсутствие `护士` и естественную передачу «have a good time».
- Быстрое редактирование: `⌘4` в TextEdit, после получения перевода 10 раз поочерёдно нажать «Редактировать»/«Готово». Никаких закрытий приложения. Изменить текст -> «Копировать» содержит правку.
- Состояние при закрытии: запуск нового перевода после закрытия панели не подставляет старый результат.
- Безопасная замена: проверить в TextEdit, что изменённое выделение не перезаписывается.
- Повторные попытки генерации: если модель всё равно теряет факты, считать тест качества неуспешным и сохранить конкретный вывод, не считать это исправленным.
- Все пункты — **тесты для выполнения на Mac**, а не прошедшие E2E тесты.
