# FreeLingo 0.5 — локальный переводчик для Apple Silicon

**Статус:** готовый исходный проект с облачной сборкой `FreeLingo-0.5-AppleSilicon.dmg`, но **не протестирован и не скомпилирован на macOS в среде разработки, где подготовлен архив**. До успешного запуска GitHub Actions и проверки на Mac не следует считать это готовым релизом.

## Основное изменение

Никаких обязательных Ollama, Rust или Xcode на компьютере конечного пользователя. Вместе с `.app` после облачной сборки будет поставляться локальный движок `llama.cpp` с поддержкой Metal. **Модели в DMG не включены**; они скачиваются через окно «Модели…» внутри FreeLingo.

| Модель | GGUF, размер | Назначение |
| --- | --- | --- |
| Qwen3 0.6B Q4_K_M | около 484 МБ | максимальная экономия памяти |
| Qwen3 1.7B Q4_K_M | около 1,28 ГБ | баланс (по умолчанию) |
| Qwen3 4B Q4_K_M | около 2,5 ГБ | лучший потенциал качества |

Размер памяти во время работы будет больше размера GGUF-файла. На машинах с 8 ГБ объединённой памяти начинать лучше с 0.6B/1.7B; для 4B желательно иметь запас памяти.

Ссылки ведут на общедоступные репозитории Hugging Face. Менеджер показывает прогресс, сохраняет модель в `~/Library/Application Support/FreeLingo/Models`, проверяет SHA-256, разрешает переключать и удалять скачанные модели. Неполная или повреждённая загрузка не активируется.

**Загрузка требует интернет.** После загрузки перевод и редактура работают на устройстве, без внешнего API. Модель запускается как отдельный локальный процесс на `127.0.0.1` со случайным токеном доступа. Исходный текст не отправляется в облако.

## Как получить DMG без установки средств разработки на Mac

1. Создай репозиторий на https://github.com (можно **публичный**, чтобы стандартные минуты Actions были бесплатными).
2. Загрузи **всё содержимое этой папки** в корень репозитория. Не загружай только ZIP, если хочешь запускать workflow: файл `.github/workflows/build-dmg.yml` должен находиться внутри репозитория.
3. Открой **Actions → Build FreeLingo DMG (Apple Silicon) → Run workflow**.
4. Когда сборка завершится успешно, открой её страницу → **Artifacts** → `FreeLingo-0.5-AppleSilicon-DMG`.
5. Скачай артефакт GitHub, распакуй ZIP артефакта и открой `FreeLingo-0.5-AppleSilicon.dmg`.
6. Перетащи `FreeLingo.app` в «Программы». При первом запуске macOS может потребовать разрешение в **Конфиденциальность и безопасность** — приложение подписано ad-hoc и **не нотаризовано Apple**.
7. В окне «Модели» выбери Qwen3 1.7B и нажми **«Скачать модель»**. После проверки SHA-256 программа переключится на неё автоматически.

После этого для повседневного использования **не требуются** Terminal, Xcode, Rust или Ollama. Для первого запуска и проверки горячих клавиш может понадобиться предоставить приложению разрешение **Универсальный доступ**; для OCR — **Запись экрана**.

Если Actions сообщает `build failed`, нужен полный лог конкретного этапа. Предварительно запуск на macOS не подтверждён.

## Основные функции проекта

- Глобальная `⌘4`: перевод выделенного текста. Альтернативы задаются в настройках.
- `⌃⌘C`: переписывание / улучшение.
- `⇧⌘2`: OCR выделенной области через macOS Vision и перевод.
- Плавающее нативное окно AppKit с «Копировать», «Редактировать…» и «Заменить».
- «Заменить» сначала пробует Accessibility; запасной путь через буфер обмена требует подтверждения пользователя.
- Главное окно: исходный текст + перевод, языки, импорт TXT/MD, экспорт TXT, история текущего сеанса.
- Менеджер локальных моделей без Ollama.
- Пока **нет** полного перевода DOCX/PDF/PPTX с сохранением вёрстки, SRT/VTT с таймкодами, облачной синхронизации.

## Для разработчиков

На Mac Apple Silicon с Xcode Command Line Tools, Rust и CMake можно выполнить:

```bash
./build-macos.sh
open dist/FreeLingo-0.5-AppleSilicon.dmg
```

Скрипт фиксирует `llama.cpp` на тег `b11798`, компилирует его вместе с Rust и AppKit, собирает `.app`, применяет локальную (ad-hoc) подпись и создаёт DMG через `hdiutil`. Модели внутри DMG отсутствуют, поэтому он существенно меньше 1 ГБ.

Облачная сборка запускает `macos-15` на Apple Silicon. Исходный код и `build-macos.sh` проверялись статически в Linux; фактический исполняемый DMG здесь **не создан**. При публикации сборки указывай отсутствие подписи Developer ID/notarization, пока не пройдена нормальная процедура Apple.

## Проверка исходников

```bash
cargo test
bash -n build-macos.sh
```

Rust тестирует инструкции и обработку ответов. Работу нативного окна, загрузку GGUF по сети, горячие клавиши и создание DMG необходимо проверить отдельно на Mac.
