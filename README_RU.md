# FreeLingo 0.6.3 — подписанное обновление через Sparkle

**Для владельца установленной FreeLingo 0.6.2:** повторно устанавливать DMG не нужно. Этот ZIP содержит ИСХОДНЫЙ КОД для публикации новой версии. Загрузите `FreeLingo063.zip` в корень GitHub-репозитория, затем в Actions запустите существующий `Publish FreeLingo signed update` с `source_zip = FreeLingo063.zip`. Если Actions завершится успешно, приложение 0.6.2 увидит 0.6.3 через меню «Проверить обновления…».

**Для разработчика:** публичный ключ Sparkle уже хранится в `SPARKLE_PUBLIC_ED_KEY`, приватный — в `SPARKLE_PRIVATE_ED_KEY`. НЕ вставляйте приватный ключ в исходники. Версия `CFBundleShortVersionString=0.6.6`, сборка `CFBundleVersion=16` (строго больше 12). Модели хранятся отдельно в `~/Library/Application Support/FreeLingo/Models/` и при обновлении .app не удаляются.

## Исправления 0.6.3

- `Редактировать`: переходы из просмотра в редактирование защищены от повторного вызова, при завершении редактирования сперва переключается first responder, а затем поле становится read-only. Пока перевод генерируется, кнопка отключена. Запоздалые результаты после закрытия панельки отбрасываются. Работа на Mac требует отдельного ручного теста.
- Русскоязычный перевод: обновлены инструкции для Qwen3 4B, уменьшена температура, контекст увеличен с 4096 до 6144 токенов, добавлены проверки и повторы при явных отклонениях по языку и некоторых фактах. Эти эвристики **не гарантируют качество DeepL** и могут потребовать дополнительного уточнения.
- Загрузка моделей, автостарт, иконка строки меню, Qwen3 4B и механизм Sparkle сохранены. Повторная загрузка модели не нужна.

## Выпуск и проверка

1. `python3 tests/check_release.py` и `python3 tests/test_autoupdate_setup.py` — статические проверки (не подтверждают запуск на macOS).
2. GitHub Actions должен успешно запустить `cargo test`, собрать arm64 .app/DMG, создать подписанный ZIP и обновить `appcast.xml` в main. Проверить новый URL и Sparkle ED-подпись.
3. В установленной **0.6.2** нажать «Проверить обновления…» и установить **0.6.3**, не открывая DMG. После перезапуска проверить номер версии.
4. Перевести `replica/story-en.txt` на уже установленной Qwen3 4B. Проверить `two brothers`, `nurse`, отсутствие иероглифов и естественность фраз.
5. Десять раз переключить «Редактировать»/«Готово» во всплывающем окне, изменить слово и скопировать результат. При падении передать отчёт `~/Library/Logs/DiagnosticReports/FreeLingo*.ips`.

**Граница проверки:** в текущей Linux-среде нет macOS SDK и Rust-компилятора. Реальный .app/DMG этой версии и её работа пока не подтверждены.

# FreeLingo 0.6.1 — точность перевода и редактирование

**Что исправлено:** кнопка «Редактировать» теперь переключает правое поле плавающего окна в режим непосредственного редактирования; «Готово» завершает редактирование. Кнопки «Копировать» и «Заменить» используют исправленный текст. В главном окне поле результата также редактируемое.

Для локального перевода добавлен детальный переводческий промпт, текст разделяется на фрагменты длиной до 1100 байт UTF-8 (с сохранением абзацев), а явная обрезка ответа и чужие иероглифы в русском результате вызывают повторную попытку. Это не гарантирует отсутствия смысловых ошибок: Qwen3 остаётся генеративной языковой моделью.

**Новая модель в каталоге:** официальная `Qwen3-8B-Q4_K_M.gguf` (~5.03 ГБ), SHA-256 `d98cdcbd03e17ce47681435b5150e34c1417f50b5c0019dd560e4882c5745785` (см. https://huggingface.co/Qwen/Qwen3-8B-GGUF/blob/main/Qwen3-8B-Q4_K_M.gguf). На Mac с достаточным объёмом памяти рекомендуем попробовать 8B. 4B остаётся альтернативой с меньшими требованиями. Ранее загруженные модели остаются на диске, их не нужно скачивать повторно.

**Проверки:** статический аудит, Python-регрессионные тесты и тесты Rust (запустятся в GitHub Actions на macOS). На текущем Linux-исполнителе отсутствуют macOS SDK и Rust-компилятор; работа нового UI и поведение модели должны быть подтверждены новой сборкой.

При сбое «Редактировать» нужен отчёт из `~/Library/Logs/DiagnosticReports/FreeLingo*.ips` (перед отправкой можно удалить личные пути). При проверке используйте один и тот же английский исходный текст и сравнивайте с предыдущим результатом по сохранению фактов, числа родственников, профессий и естественности русского языка.

# Архив предыдущей версии 0.6.0

Нативное приложение для macOS 15+, Rust + AppKit, локальные GGUF-модели через llama.cpp/Metal.

**Состояние:** изменения в 0.6.0 прошли проверки исходников, но пока не собраны и не проверены на реальном Mac. Уже существующая сборка 0.5.4 не содержит этих функций; для обновления требуется один новый DMG. Дальнейшие обновления могут устанавливаться через Sparkle после настройки подписи.

## Новое в 0.6.0

- **Иконка в строке меню:** контрастная буква F со стрелкой, Template Image с автоматическим переключением под светлую/тёмную тему.
- **Без значка Dock:** «Показывать значок в Dock» в меню строки меню и в «Настройках». При отключении FreeLingo остаётся доступен в строке меню, его окна открываются вручную, приложение не завершается при закрытии окон.
- **Автозапуск:** «Запускать при входе в macOS» настраивается там же через `SMAppService.mainAppService` (macOS 13+). При отключённом Dock FreeLingo открывается в фоне. macOS может запросить разрешение на Login Items; если регистрация отклонена, показывается причина.
- **Обновления:** в меню «Проверить обновления…». Sparkle 2 проверяет appcast по HTTPS, сверяет цифровую подпись EdDSA и устанавливает новый ZIP приложения. Без настроенного публичного ключа пункт честно объясняет, что обновления ещё не активированы.
- Локальные модели не входят в `.app` и хранятся отдельно, поэтому обновление приложения не должно удалять их. Для запуска локального перевода интернет не требуется после загрузки модели.

## Сборка без установки Rust и Xcode пользователю

В репозитории должны быть все файлы, включая `.github/workflows/build-dmg.yml`. В GitHub открой Actions → **Build FreeLingo DMG (Apple Silicon)** → **Run workflow**. После успешной сборки в Artifacts будет `FreeLingo-AppleSilicon-DMG` с DMG и ZIP.

Пользователю достаточно установить DMG один раз. Приложение ad-hoc подписано, но **не нотарифицировано** в Apple (может появиться запрос безопасности). Для глобальных хоткеев потребуется «Универсальный доступ», для OCR — разрешение экрана.

## Настройка полноценных автоматических обновлений — один раз владельцу репозитория

Sparkle не устанавливает произвольные неподписанные обновления. Требуются **пара ключей EdDSA** и публикация GitHub Releases.

1. Один раз получить ключи официальной утилитой Sparkle `bin/generate_keys` из [выпуска Sparkle](https://github.com/sparkle-project/Sparkle/releases/tag/2.9.6). Она умеет `-x <файл>` для экспорта приватного ключа. Ключи создаются локально на доверенном Mac, не в публичном GitHub. Не отправляй секретный ключ в чат и не загружай его в репозиторий.
2. В GitHub → FreeLingo → Settings → Secrets and variables → Actions → **Variables** создать `SPARKLE_PUBLIC_ED_KEY` со значением публичного ключа, который выдала утилита.
3. Там же в **Secrets** создать `SPARKLE_PRIVATE_ED_KEY` с содержимым экспортированного секретного ключа. Храни резервную копию ключа отдельно и не публикуй его.
4. Собрать первую версию с публичным ключом через **Publish signed FreeLingo release** в Actions. Она создаст GitHub Release, подпишет ZIP и запишет appcast.xml в main. Первый установочный DMG этой версии нужно поставить вручную; последующие подписанные релизы будут доступны из приложения.
5. Для следующих выпусков увеличивать `CFBundleShortVersionString` и `CFBundleVersion` в `assets/Info.plist` и запускать **Publish signed FreeLingo release**. Не изменять ключ подписи после первого выпуска без документированной процедуры ротации.

**Не выкладывай приватный ключ в публичные файлы, Actions Artifacts или сообщения чата.** Если ключи не настроены, приложение продолжит работать и переводить текст, но не станет устанавливать обновления из неизвестного источника.

## Тестирование на Mac

1. Скачать и активировать модель (Qwen3 0.6B для начала); убедиться, что приложение не закрывается при 100%.
2. Закрыть главное окно: значок в строке меню остаётся. Выбрать «Показывать значок в Dock» — проверить переключение.
3. Включить автозапуск, проверить «Системные настройки → Основные → Объекты входа и расширения» и перезайти в систему. FreeLingo должен остаться в меню, без внезапного главного окна при скрытом Dock.
4. Проверить `⌘4` в TextEdit, «Копировать» и «Заменить». Убедиться, что при отсутствии разрешения Accessibility приложение не изменяет другой текст.
5. Проверить «Проверить обновления…». Пока appcast/ключ не настроены — увидеть информативное сообщение, а не обещание установленных обновлений.
6. После следующей подписанной версии — выполнить реальное обновление без DMG и проверить, что модель осталась на месте.

Тесты в среде разработки (без macOS GUI): `python3 tests/check_release.py` и `bash -n build-macos.sh`. При необходимости полный macOS CI делает `python3 tests/smoke_macos.py` с тестовой моделью.

Отчёт о реализованности: `replica/features.csv`. Не считать успешную компиляцию подтверждением работы UI на Mac.

## FreeLingo 0.6.4 — специализированный перевод

- В менеджере моделей теперь есть **Hy-MT2 7B Q4_K_M** (≈4,62 ГБ) и **Hy-MT2 1.8B Q4_K_M** (≈1,13 ГБ) от Tencent. Обе модели скачиваются по HTTPS, проверяются SHA-256, затем работают офлайн. Используется обычный K-quants GGUF, а не экспериментальная STQ-квантовка.
- Основные языки: **русский**, английский, упрощённый китайский, французский, итальянский. Поддерживается перевод в любую сторону между ними через выбор языка назначения; исходный язык модель распознаёт из текста. Другие ранее доступные языки в интерфейсе не удалены. Для финского с Hy-MT2 предусмотрено явное сообщение о неподдерживаемом языке.
- Для Hy-MT2 используется отдельный формат запроса **без system prompt** и параметры sampling из официальной документации: temperature 0.7 / top_p 0.6 / top_k 20 / repeat_penalty 1.05.
- Hy-MT2 поддерживает *перевод*, а не переписывание. Для команды «Улучшить текст» оставлена Qwen3. Старые модели и настройки сохраняются после обновления.
- Подпись Sparkle и канал appcast сохранены, версия приложения — 0.6.4, сборка 14.
- Качество и запуск новой модели в полноценной Apple Silicon сборке необходимо проверить: локальные статические тесты и GGUF-манифест не являются заменой теста на Mac.

Источники модели и лицензии: https://huggingface.co/tencent/Hy-MT2-7B-GGUF и https://huggingface.co/tencent/Hy-MT2-1.8B-GGUF (Apache-2.0).

Для проверки новой модели на runner macOS после сборки запусти `python3 tests/smoke_hy_macos.py`. Скрипт скачает 1,13 ГБ и проверит запуск и выдачу пяти языков (не качество). Сам скрипт пока не запускался на macOS.

### v0.6.6: защита разрешений и второй этап перевода

Из-за `codesign --sign -` система macOS может сбрасывать выданное разрешение после каждого обновления. Код сборки теперь принимает `SIGNING_IDENTITY` и `SIGNING_KEYCHAIN`; пока они не установлены, проблема **не решена**. Подробности: `RELEASE_0.6.6_RU.md`.

Меню «Литературная вычитка русского (медленнее)» даёт экспериментальный двухэтапный перевод: Hy-MT2 + Qwen3. Если Qwen не скачана, FreeLingo предлагает установить её в разделе моделей.
