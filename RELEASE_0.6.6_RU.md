# FreeLingo 0.6.6 — экспериментальная вычитка и постоянная подпись

- Меню → «Литературная вычитка русского (медленнее)». По умолчанию **выключена**. Только Hy-MT2 → русский. Требуется локально установленная Qwen3 4B или 8B. После перевода отдельный запрос к Qwen получает оригинал и черновик; базовые проверки отклоняют слишком короткий, длинный и искажённый ответ. Это эксперимент, не гарантия литературного качества.
- Поддержка `SIGNING_IDENTITY`, `SIGNING_KEYCHAIN`, `REQUIRE_STABLE_SIGNING`, `SIGNING_DEVELOPER_ID`. До предоставления *постоянного* сертификата CI продолжает ad-hoc и macOS может снова спрашивать разрешения. **Sparkle Ed25519 не заменяет macOS Code Signing.**
- Для публикации с сохранением Accessibility между версиями добавь в GitHub Actions импорт P12 постоянного сертификата, подписывай следующие версии одним identity и фиксированным Bundle ID; для распространения другим пользователям применяй Developer ID + notarization.
- Статические тесты не подтверждают работу на macOS или улучшение качества перевода.
