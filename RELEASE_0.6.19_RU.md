# FreeLingo 0.6.19 — Glass для macOS

Версия приложения и ядра: 0.6.19, номер сборки: 29. Основа — FreeLingo0618.zip из тега v0.6.18 репозитория igrizlikov/FreeLingo.

## Изменения

- Нативная боковая панель NSVisualEffectView с материалом Sidebar и SF Symbols: текст, улучшение текста, файлы, история, модели и настройки.
- Прозрачная область заголовка, крупная панель исходного и целевого языков, отображение автоопределённого языка.
- Два скруглённых редактора с системной типографикой, интерлиньяжем, счётчиками знаков, очисткой и копированием. Готовый перевод по-прежнему можно редактировать.
- Акцентная системная кнопка «Перевести», дополнительное сочетание ⌘Return. Существующее глобальное ⌘4 сохранено.
- Статус выбранной локальной модели: название, квантование, объём, установка/загрузка/проверка и обработка главного запроса. «Установлена» означает наличие файла, а не уже загруженную в GPU модель.
- Светлая и тёмная темы следуют системе. Минимальный размер окна — 1000×600 точек, чтобы сохранить полноценные две колонки и боковую панель.
- При переходе в историю сохраняется готовый перевод; при возвращении он восстанавливается. Во время основного потока переключение разделов блокируется; очистка остаётся доступна и отсекает устаревшие результаты.
- В сборке явно указан NaturalLanguage.framework; добавлен Cargo.lock для фиксации зависимостей.

Движок src/lib.rs, интерфейс FreeLingoCore.h и каталог ModelManager.inc совпадают с 0.6.18 побайтно. TranslateGemma 12B Q4_K_M, параметры генерации, Metal, KV-кэш, автоопределение и Sparkle не перенастраивались. Импорт остаётся TXT/MD, экспорт — TXT; поддержка PDF/DOCX не добавлялась.

## Точный статус визуальной проверки

Окно настоящего тестового .app было открыто и просмотрено через интерфейс macOS. На первоначальном просмотре выявлена обрезанная кнопка моделей; она сокращена до «Модели…». Исправлено название действия при переходе в историю.

После исправлений четыре изображения получены рендерингом настоящих AppKit views тестового приложения, а не HTML-макетом: светлая/тёмная тема, 1180×740 и 1000×578 точек содержимого. Все четыре просмотрены: поля, подписи, кнопки и статус помещаются. Текст на этих изображениях задан тестом и не является скриншотом результата реального инференса. Снимки содержимого не показывают системную рамку; размытие за окном и активный системный акцент достоверно оцениваются только в живом окне.

Повторное подключение инструмента управления к основному приложению после финальной сборки завершалось тайм-аутом. Поэтому финальные рендеры и прошедшие AppKit-тесты не выдаются за полный ручной прогон всех экранов. ⌘4 с выделением в стороннем приложении, файловые диалоги, все вкладки настроек, загрузка модели и реальное обновление Sparkle сквозным UI-сценарием не проверялись. Их обработчики сохранены; имеющиеся статические проверки прошли. Полная проверка macOS 15 отдельно не выполнялась.

## GitHub Actions

Архив FreeLingo0619.zip содержит исходники от корня, включая .github/workflows, без промежуточной папки. Для существующего ZIP-import workflow загрузите архив в корень репозитория и укажите source_zip=FreeLingo0619.zip. Внутри архива это уже значение по умолчанию. Существующие требования ключей Sparkle и схемы подписания сохранены; секреты в архив не включены.

После обычной сборки доступна дополнительная проверка интерфейса:

```sh
bash tests/run_glass_macos.sh
```

С первым аргументом-каталогом она также сохраняет четыре изображения. Для реальной проверки потока с установленной 12B:

```sh
bash tests/run_inference_0619.sh /path/to/translategemma-12b-it-Q4_K_M.gguf
```

Оба скрипта по умолчанию используют target/aarch64-apple-darwin/release/libfreelingo_core.a; переменная FL_TEST_CORE позволяет указать путь для host-сборки. AppKit-проверке требуется графическая сессия macOS. Проверка инференса создаёт обычные локальные диагностические журналы FreeLingo и использует только синтетический текст.
